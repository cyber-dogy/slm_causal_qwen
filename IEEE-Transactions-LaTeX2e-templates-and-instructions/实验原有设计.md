## 1. 实验总体目标

### 1.1 核心科学问题

**多模态因果稳定表征学习（Multimodal Causal-Stable Representation Learning）**

在激光选区熔化（Selective Laser Melting, SLM）增材制造过程中，解决以下挑战：

| 挑战                 | 描述                               | 本实验解决方案          |
| -------------------- | ---------------------------------- | ----------------------- |
| **跨工况泛化** | 工艺参数变化时模型失效             | 因果干预 + 稳定表征分离 |
| **几何域迁移** | 简单形状→复杂零件性能下降         | 域不变特征学习          |
| **多模态融合** | RGB+IR 信息如何有效整合            | 可靠性估计器动态加权    |
| **异常检测**   | 识别高能翘曲(HEW)和低能未熔合(LEL) | 变化检测 + 分类器       |

### 1.2 数据集架构

```
Causal_Image_Data (Data1/源域)          Causal_Image_Data2 (Data2/目标域)
├── 立方体试样 (20×20×10mm)              ├── 复杂结构件
├── 层厚: 30μm                           ├── 薄壁、悬空、腔体等特征
├── 相机: RGB双目 + IR单目               ├── 相同相机配置
└── 22个condition × ~13层               └── 22个condition × ~18层
```

### 2.1 命名规则

```
[类别]-[编号]

类别: Base | Equiv | Gen | High | Low
编号: 01-08 (按实验设计顺序)
```

### 2.2 详细字段对照表

#### Base 组（基准正常）

| Condition         | 功率(W) | 速度(mm/s) | 间距(mm) | 能量密度 | 标签   | 设计目的                 |
| ----------------- | ------- | ---------- | -------- | -------- | ------ | ------------------------ |
| **Base-01** | 200     | 800        | 0.10     | 1.50     | normal | 主基准，所有比较的参考点 |
| **Base-02** | 200     | 800        | 0.10     | 1.50     | normal | 重复性验证，批次间一致性 |

**关键说明**:

- Base-01/02 参数完全相同，用于验证工艺重复性
- 能量密度公式: E = P/(v×h)，单位 J/mm³
- 这是"标准"工艺窗口的中心点

---

#### Equiv 组（等效验证）

| Condition          | 功率(W) | 速度(mm/s) | 间距(mm) | 能量密度 | 标签   | 设计目的              |
| ------------------ | ------- | ---------- | -------- | -------- | ------ | --------------------- |
| **Equiv-01** | 250     | 1000       | 0.10     | 1.50     | normal | 高功率+高速度等效组合 |
| **Equiv-02** | 180     | 720        | 0.10     | 1.50     | normal | 低功率+低速度等效组合 |

**关键说明**:

- **等效原理**: 不同P/v组合但相同能量密度应产生相似结果
- 验证模型是否能识别"参数不同但效果相同"的工况
- 用于 **L_equiv（等效一致性损失）** 的训练

**科学意义**:

```
如果 E₁ = E₂，则 f(表征|condition₁) ≈ f(表征|condition₂)
```

#### Gen 组（泛化/扰动测试）

| Condition        | 功率(W) | 速度(mm/s) | 间距(mm)       | 扫描策略         | 标签   | 设计目的                       |
| ---------------- | ------- | ---------- | -------------- | ---------------- | ------ | ------------------------------ |
| **Gen-01** | 200     | 800        | 0.10           | **Zigzag** | normal | 扫描策略变化（vs Base Stripe） |
| **Gen-02** | 200     | 800        | **0.08** | Stripe           | normal | 间距减小（+20%能量）           |
| **Gen-03** | 200     | 800        | **0.12** | Stripe           | normal | 间距增大（-17%能量）           |

**关键说明**:

- **Gen-01**: 扫描策略从 Stripe → Zigzag，热历史改变
- **Gen-02/03**: 间距扰动，能量密度微小变化但仍属正常
- 用于测试模型对**工艺微扰动**的鲁棒性
- 属于 **L_env（环境一致性损失）** 的约束对象

**与 Base 对比**:

```
Base-01:  P=200, v=800, h=0.10, strategy=Stripe
Gen-01:   P=200, v=800, h=0.10, strategy=Zigzag  ← 仅策略变
Gen-02:   P=200, v=800, h=0.08, strategy=Stripe  ← 仅间距变
Gen-03:   P=200, v=800, h=0.12, strategy=Stripe  ← 仅间距变
```

## 3. 实验设计原理

### 3.1 因果推断框架

#### 核心问题: 为什么需要因果学习？

**传统机器学习的局限**:

```
P(Y|X) - 关联学习
问题: P(Y|X) 随环境变化（域漂移）
```

**因果学习的优势**:

```
P(Y|do(X)) - 干预学习
优势: 对分布变化鲁棒
```

#### 本实验的因果图

```
        工艺参数 (P, v, h, strategy)
                ↓
    ┌───────────┼───────────┐
    ↓           ↓           ↓
  稳定因子 C   不稳定因子 V  虚假相关 S
    │           │           │
    └───────┬───┘           │
            ↓               ↓
        多模态图像      拍摄条件
        (RGB+IR)      (光照、角度)
            │               │
            └───────┬───────┘
                    ↓
                缺陷标签 Y
```

**设计目标**:

- **C (Causal)**: 与缺陷因果关系稳定的特征（如熔池温度场）
- **V (Variant)**: 随工况变化的特征（如绝对亮度）
- **S (Spurious)**: 与标签相关但非因果的特征（如背景纹理）

### 3.2 为什么会有"反直觉"设计？

#### 案例1: High-01（高能但正常）

**为什么设计这个？**

```
假设模型学到: 高功率 → 异常
测试时遇到:   高功率 + 高速度（Equiv-01）
结果:        误判为异常！

问题: 模型学到了虚假相关（功率↑→异常）
      而非真正因果（能量密度↑→异常）
```

**正确学习**:

```
因果因子: E = P/(v×h) 
High-01:  E=2.25 → 正常（虽然P=300W）
High-02:  E=2.92 → HEW（因为E>阈值）
```

#### 案例2: Gen-01（Zigzag策略但正常）

**为什么设计这个？**

```
如果模型学到: Stripe扫描 → 正常
测试时遇到:   Zigzag扫描
结果:        误判！

问题: 扫描策略本身不决定缺陷，能量密度才决定
```

### 3.3 各 Loss 的设计原理

#### L_equiv（等效一致性损失）

**目的**: 强制模型识别"不同参数但等效结果"

```python
# Base vs Equiv 应有相似表征
h_c(Base-01) ≈ h_c(Equiv-01)  # 虽然P,v不同，但E相同
```

**科学意义**:

- 阻止模型过拟合到特定参数组合
- 学习"能量密度"这个因果因子

#### L_env（环境一致性损失）

**目的**: 约束同 condition 内样本表征一致

```python
# Gen-01 内部样本应相似（即使层数不同）
Loss = Var(h_c | condition=Gen-01)
```

**为什么只对 Gen 应用？**

- Gen 是**正常工况的扰动**，需要一致性
- High-07/08 是**异常**，内部可以有差异（不同层异常程度不同）

#### L_cm（跨模态一致性损失）

**目的**: RGB 和 IR 应提取一致的变化信息

```python
# Δf_RGB ≈ Δf_IR
Loss = ||(f_post^RGB - f_pre^RGB) - (f_post^IR - f_pre^IR)||
```

#### L_jepa（预测一致性损失）

**目的**: 学习时序稳定的表征

```python
# 从 layer N 预测 layer N+1
Pred(f_N+1) ≈ f_N+1
```

## 4. 域划分策略

### 4.1 域定义

```
源域 (Source Domain): Data1 (立方体)
├── 训练集: Base, Equiv, Gen, High-01, Low-01 (正常+边界)
├── 验证集: High-02/03/04, Low-02/03/04 (标准异常)
└── 特点: 简单几何，层间一致性高

目标域 (Target Domain): Data2 (复杂结构)
├── 测试集: 所有 condition
└── 特点: 薄壁、悬空、热历史复杂

OOD 测试 (Out-of-Distribution): 
├── High-07/08: 复合扰动异常
└── 目的: 测试对未见异常模式的泛化
```

### 4.2 为什么这样划分？

**真实工业场景模拟**:

```
阶段1（源域训练）: 在标准试样上建立模型
阶段2（目标域测试）: 应用到真实零件
挑战: 几何变化导致域漂移
```

**MCSR-Net 的解决方案**:

```
1. 变化检测: Δf = f_post - f_pre（去除几何静态特征）
2. 稳定表征: h_c = Aggregator(Δf_RGB, Δf_IR)
3. 域不变: h_c 对几何不敏感，只对缺陷敏感
```

## 5. 标签定义与分类逻辑

### 5.1 标签体系

#### 二分类（实际使用）

| 标签                   | 含义        | Condition                          |
| ---------------------- | ----------- | ---------------------------------- |
| **0 (normal)**   | 正常/无缺陷 | Base, Equiv, Gen, High-01, Low-01  |
| **1 (abnormal)** | 异常        | High-02~08 (HEW), Low-02~07 (LEL) |

#### 细分类别（用于分析）

| 类别          | 全称                | 缺陷机制   | 视觉特征             |
| ------------- | ------------------- | ---------- | -------------------- |
| **NOR** | Normal              | -          | 熔道均匀，无明显缺陷 |
| **HEW** | High Energy Warping | 热应力过大 | 层间翘曲、过烧、球化 |
| **LEL** | Lack of Fusion      | 能量不足   | 未熔合孔洞、分层     |

### 5.2 标签边界定义

```
能量密度 E (J/mm³)

0.5 ─────────────────────────────────────
    │           LEL 区域
0.9 ─┬───────────────────────────────────
    │  [Low-01] normal 边界
1.5 ─┼────────── Base/Equiv/Gen ───────── 标准工况
    │
2.5 ─┬───────────────────────────────────
    │  [High-01] normal 边界
    │           HEW 区域
5.0 ─────────────────────────────────────

边界条件（High-01, Low-01）的设计目的:
- 测试模型对"边界案例"的判断能力
- 验证模型是否真正理解能量密度与缺陷的关系
- 避免简单阈值分类（E>2.5→异常 这种硬规则）
```

### 5.3 High-07/08 的特殊性

虽然 High-07/08 也是 HEW，但与 High-02~06 有区别：

| 特征               | High-02~06    | High-07/08         |
| ------------------ | ------------- | ------------------ |
| **参数扰动** | 仅功率变化    | 功率+速度复合变化  |
| **扫描策略** | 部分用 Zigzag | 标准 Stripe        |
| **用途**     | 标准异常训练  | OOD/复合异常测试   |
| **L_env**    | 不应用        | 不应用（现为异常） |

**为什么 High-07/08 是 HEW 而非新类别？**

- 缺陷机制相同：都是能量过高导致的热应力问题
- 区别仅在于"扰动模式"不同
- 在二分类中统一为 abnormal=1，细分为 HEW

## 6. 实验验证清单

### 6.1 模型应能正确区分

| 对比组                       | 预期结果                   | 验证能力                   |
| ---------------------------- | -------------------------- | -------------------------- |
| Base-01 vs High-01           | 不同输入，相同输出(normal) | 理解能量密度非单一参数决定 |
| High-01 vs High-02           | 相似输入，不同输出         | 识别能量密度阈值           |
| Equiv-01 vs Base-01          | 不同参数，相同输出         | 等效性识别                 |
| Gen-01 vs Base-01            | 策略不同，输出相同         | 策略不变性                 |
| Data1 vs Data2 (同condition) | 输出一致                   | 几何域迁移                 |

### 6.2 失败案例分析

如果模型在以下情况失败，说明需要改进：

| 失败场景              | 可能原因               | 解决方案           |
| --------------------- | ---------------------- | ------------------ |
| 将 High-01 误判为异常 | 过拟合到"高功率→异常" | 加强 L_equiv       |
| 将 Gen-01 误判为异常  | 过拟合到扫描策略       | 加强 L_env         |
| Data2 性能下降        | 几何域漂移             | 强化变化检测       |
| High-07/08 检测失败   | 复合异常识别差         | 增加训练样本多样性 |
